## How defaults apply

GitHub uses a file from this repository only when a repository has no file of
its own with the same name. To override a default, add the file to that
repository — in its root, `docs/`, or `.github/`.

Issue templates are the exception: a repository with its own
`.github/ISSUE_TEMPLATE/` folder uses none of the defaults here.
