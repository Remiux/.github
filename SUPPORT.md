# Getting help

This page applies to every repository in the
[Remiux](https://github.com/Remiux) organization that has no support page of
its own.

## Using a repository

1. Read the repository's README and any documentation it links to.
2. Search the repository's open and closed issues. Someone may have asked the
   same question.
3. If you find no answer, open an issue in that repository. Say what you are
   trying to do, what you tried, and what happened.

## Something is broken

Open an issue with the **Bug report** form in the affected repository.

## A security vulnerability

Do not open an issue. Follow the
[security policy](https://github.com/Remiux/.github/blob/main/SECURITY.md).

## Working with Remiux

For custom solutions, products, or anything outside a repository, go to
[remiux.com](https://remiux.com).
